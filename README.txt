# Mark's Savanna Stock Website

## Open the website

1. Extract the ZIP file.
2. Open the extracted `outputs` folder.
3. Double-click `landing.html` to view the site.
4. Use the site navigation to open the sign-in, account creation, and customer account pages.

Keep all the files and folders together. The HTML pages use the included icons and PWA files.

## Notes

- This package is a static website prototype. Account details are stored in the visitor's browser, so they do not sync between devices.
- The backend folder contains separate API starter code. It is not connected to the pages by default and needs configuration before deployment.
- M-Pesa live payments are not enabled. Do not enter real payment credentials into a demo.
- To install the site as an app or share it as a public website, deploy it to a web host with HTTPS. Opening the HTML file directly is for a local preview.
